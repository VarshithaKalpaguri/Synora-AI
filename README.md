# 🤖 Synora AI

Synora AI is a friendly local AI chatbot built with
Streamlit, Ollama and Gemma 3.

It provides a simple conversational interface for
learning, coding, brainstorming and general questions.

## ✨ Features

- 💬 Conversational AI
- 🧠 Session-based conversation memory
- 💻 Programming assistance
- 💡 Project brainstorming
- 🎨 Modern responsive UI
- 🔒 Local AI inference
- ⚡ Gemma 3 1B
- 🖥️ Streamlit interface

## 🛠️ Tech Stack

- Python
- Streamlit
- Ollama
- Gemma 3 1B
